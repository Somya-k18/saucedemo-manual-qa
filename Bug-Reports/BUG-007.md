# BUG-007 — Excessive Vertical Spacing in Mobile Product Cards

**Module:** Products  
**Category:** UI / Responsive Layout  
**Severity:** Medium (Provisional)  
**Priority:** Medium (Provisional)  
**Status:** Open  
**Environment:** Windows, Google Chrome  
**Viewports:** Desktop (1366 × 768), Tablet (768 × 1024), Mobile (390 × 844)

## Description

During responsive compatibility testing, excessive vertical spacing was observed within product cards at the Mobile viewport size. This spacing pushes the product price and Add to Cart controls farther down the page, requiring additional scrolling to reach them.

The issue was observed at the Mobile viewport size. The same behavior was not observed during testing at Desktop and Tablet viewport sizes.

## Preconditions

- SauceDemo is accessible.
- The user can log in with `standard_user`.
- The Products page is available.
- The browser viewport is set to the Mobile size of 390 × 844.

## Steps to Reproduce

1. Log in to SauceDemo using `standard_user`.
2. Navigate to the Products page.
3. Set the browser viewport to 390 × 844.
4. Inspect the vertical spacing within the displayed product cards.
5. Observe the position of the product price and Add to Cart controls.
6. Repeat the checks at Desktop (1366 × 768) and Tablet (768 × 1024) viewport sizes for comparison.

## Expected Result

Product cards should use appropriate vertical spacing at the Mobile viewport size so that product information, prices, and Add to Cart controls remain arranged in a usable layout without unnecessary gaps.

## Actual Result

Excessive vertical spacing is visible within product cards at the Mobile viewport size. The price and Add to Cart controls are pushed farther down, requiring additional scrolling to reach them.

The same issue was not observed at Desktop and Tablet viewport sizes during this test.
