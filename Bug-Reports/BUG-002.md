# BUG-002 — Dynamic Catalog continuously generates duplicate products while scrolling

**Bug ID:** BUG-002

**Module:** Dynamic Catalog

**Severity:** Medium

**Priority:** Medium

**Status:** Open

**Test Type:** Manual Testing

**Related Test Case:** TC-DYN-003

**Environment:** SauceDemo Web Application

## Title

Dynamic Catalog continuously generates duplicate products while scrolling.

## Preconditions

* User is logged in with a valid account.
* Dynamic Catalog is accessible from the application menu.
* Lazy Load section is available.

## Steps to Reproduce

1. Log in to SauceDemo using a valid user account.
2. Open the application menu.
3. Select **Dynamic Catalog**.
4. Open the **Lazy Load** section.
5. Scroll down through the product list.
6. Continue scrolling and observe the products being loaded.
7. Compare product names and other visible product information as additional products appear.

## Expected Result

Scrolling through the Dynamic Catalog should load the available catalog content without continuously generating unintended duplicate product entries.

## Actual Result

As the user continues scrolling, duplicate product entries appear in the catalog.

The duplication continues as scrolling proceeds, resulting in repeated products being added to the list.

## Impact

* Makes the catalog unnecessarily long.
* Causes repeated product entries.
* Makes it more difficult for users to browse and identify unique products.
* May indicate incorrect handling of dynamic/lazy-loaded catalog data.

## Reproducibility

**Reproducible:** Yes

Duplicate products were observed repeatedly while scrolling through the Lazy Load section.
