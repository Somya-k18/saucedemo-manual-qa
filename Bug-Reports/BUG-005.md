# BUG-005 — Dynamic Catalog Images Are Clipped

**Module:** Dynamic Catalog  
**Category:** UI / Responsive Layout  
**Severity:** Medium  
**Priority:** Medium  
**Status:** Open  
**Environment:** Windows, Google Chrome  
**Viewports:** Desktop (1366 × 768), Tablet (768 × 1024), Mobile (390 × 844)

## Description

Images in the Dynamic Catalog are visibly clipped within their displayed areas. The issue was observed in all three catalog options: Lazy Load, Spinner, and Slider.

The clipping was reproduced during responsive compatibility testing on Tablet and Mobile. Similar clipping had also been observed during Desktop testing.

## Preconditions

- SauceDemo is accessible.
- The user can log in with `standard_user`.
- The Dynamic Catalog page or section is available.

## Steps to Reproduce

1. Log in to SauceDemo.
2. Navigate to the Dynamic Catalog.
3. Open the Lazy Load option.
4. Inspect the displayed product images for clipping.
5. Repeat the inspection for the Spinner and Slider options.
6. Repeat the checks at Desktop, Tablet, and Mobile viewport sizes.

## Expected Result

Images should display within their intended containers without unintended clipping that obscures the displayed content.

## Actual Result

Images are visibly clipped in Lazy Load, Spinner, and Slider. The issue was reproduced at Desktop, Tablet, and Mobile viewport sizes.
