# BUG-006 — Invalid Credentials Error Message Is Partially Clipped

**Module:** Authentication  
**Category:** UI / Responsive Layout  
**Severity:** Medium (Provisional)  
**Priority:** Medium (Provisional)  
**Status:** Open  
**Environment:** Windows, Google Chrome  
**Viewports:** Desktop (1366 × 768), Tablet (768 × 1024), Mobile (390 × 844)

## Description

The invalid-credentials error message is partially clipped within its red error container at Desktop and Mobile viewport sizes. The issue was observed during responsive compatibility testing.

At the Tablet viewport size, the error message was displayed without the same clipping.

## Preconditions

- SauceDemo is accessible.
- The login page is available.
- Invalid login credentials are available for testing.

## Steps to Reproduce

1. Open SauceDemo in Google Chrome.
2. Navigate to the login page.
3. Enter an invalid username and password.
4. Click the Login button.
5. Observe the error message displayed on the login page.
6. Repeat the check at Desktop, Tablet, and Mobile viewport sizes.

## Expected Result

The complete invalid-credentials error message should be visible within its container at all tested viewport sizes, without clipping or obscured text.

## Actual Result

The invalid-credentials error message is partially clipped within the red error container at Desktop and Mobile viewport sizes. The same clipping was not observed at the Tablet viewport size.
